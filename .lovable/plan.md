# Simplify the system background

## Goal
Make all signed-in pages feel like a focused school management system by removing unnecessary tinted page backgrounds.

## Changes
- Replace the green-tinted main page background with a clean neutral system surface.
- Keep content panels white and use subtle borders instead of decorative color blocks.
- Retain the school’s emerald and coral colors only for navigation, actions, and status indicators.
- Apply matching neutral surfaces in dark mode.
- Verify the shared layout remains clear on desktop and mobile.

## Technical details
- Update shared semantic color tokens so the change applies consistently across all pages.
- Remove decorative global gradients where they are not needed, without changing any page functionality.
